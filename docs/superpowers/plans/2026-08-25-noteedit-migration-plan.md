# Écran 4 (NoteEdit / mode Zen) — Migration Direction A — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recompose `web/src/views/Notes/NoteEdit.vue` onto the Direction A design system
(tokens + primitives) without removing any existing functionality, guided by the validated
Claude Design mockup `NoteEdit.dc.html` where it doesn't conflict with real functionality.

**Architecture:** Extract 4 focused sub-components (2 existing raw modals become
`BaseModal`-backed components, 1 raw modal is replaced by a persistent sidebar, 1 new sidebar
component is added) out of the 3025-line monolith; retone every raw Tailwind color class
(`slate-*`/`rose-*`/`indigo-*`/`emerald-*`/`amber-*`/`blue-*`/`purple-*`/`pink-*`/`cyan-*`/
`teal-*`/`sky-*`) to the project's design tokens, both in the static template and in the HTML
strings generated by `renderMarkup`/`renderSm2Buttons`. Fix a real error-state gap found during
inventory (silent failure on note load). Zero behavior change to the active-reading placeholder
engine, autosave, sharing, PDF export, or Zen mode — only presentation changes.

**Tech Stack:** Vue 3 `<script setup lang="ts">`, Vitest + `@vue/test-utils`, existing Direction A
primitives (`BaseModal`, `BaseCard`, `BaseButton`, `BaseBadge`, `BaseField`, `BaseInput`,
`Tabs`), Pinia stores (`notes`, `binders`, `tags`).

**Spec:** `docs/superpowers/plans/2026-08-25-noteedit-migration-spec.md` — full inventory,
states, token mapping table, and the explicit decisions (AI modal → sidebar, toolbar stays
text-label, breadcrumb addition, print CSS exemption). Read it before starting any task.

## Global Constraints

- Zero functionality removed. Every action recensed in the spec's inventory must still be
  reachable and behave identically after this plan, except where the spec explicitly says
  otherwise (AI modal → sidebar card, same `startAiActivity` routing).
- `<script setup lang="ts">` only, no `any`. API calls only in `stores/`/`services/` (existing
  gap on this file — `api.get`/`api.patch` direct calls — is pre-existing and OUT OF SCOPE for
  this plan; do not touch it).
- No raw style values in new/touched code (`web/CLAUDE.md`): always a token. Exception: the
  `@media print` `<style>` block (lines ~2766-2944) stays on raw hex — print output must always
  render on white paper regardless of app theme. Do not touch that block in any task.
- Tactile targets ≥44px, AA contrast, `prefers-reduced-motion` respected on any new/changed
  transition.
- Test-first (TDD) for every behavioral change. Pure visual retoning (class swaps with zero
  behavior change) does not need new tests, but must not break existing ones.
- Commit after each task.
